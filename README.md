# Introduction

This project demonstrates how to automate quality and consistency checks across different workflows using linters. It is organized into three modules:

* **`code-linting`**: Best practices for using linters to improve Python code quality.
* **`contract-linting`**: Techniques for validating and enforcing standards during contract generation.
* **`doc-linting`**: Methods for enforcing style guides and formatting rules in project documentation.

Please refer to `README.md` in respective folders to know more about each module
